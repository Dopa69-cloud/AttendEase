# CA-3 report outline


1. **Title page:** AttendEase, course, team names/PRNs, division, faculty, date.
2. **Introduction:** Attendance problem and objectives.
3. **Project overview:** Features, users, tech stack, limitations.
4. **Repository investigation:** Repository URL, license, files, README, contribution guide, Git history.
5. **Issue investigation:** Real issue link, reproduction steps, expected/actual behavior, evidence.
6. **Bug investigation:** Environment, root cause, fix, regression tests and actual outcomes.
7. **Contribution process:** Fork, clone, branch, edits, testing, commit, push, PR.
8. **Pull request investigation:** An actual PR if required; explain purpose, changed files, review, checks, status.
9. **Practical observations:** Usability, edge cases, storage, accessibility, maintainability.
10. **Changes/contribution:** Your own commit/PR links and before/after evidence.
11. **Conclusion:** Lessons in debugging, testing, version control, and review.
12. **References:** Repository, official documentation, and sources actually used.
